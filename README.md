# PaumeDoré
![paume dore png logo](Logo%20(3).png)

> Turn lost time into golden time.

PaumeDoré is a minimalist **Pomodoro-inspired productivity app** built with **React**, and based on a Figma design.

It combines a focus timer, todo list, and productivity counters in one focused interface.

The name is a wordplay on the French words **“paumé”** (lost) and **“doré”** (gold).

## Features

- Pomodoro timer with work, short break and long break cycles
- Customizable timer settings
- Todo list with completion tracking
- Completed tasks are linked to the current Pomodoro phase
- Activity counters for work and break sessions
- Visual feedback based on the current activity

## Tech Stack

- **React** (hooks, Context API for shared timer/todo state)
- **Vite**
- **JavaScript (JSX)** and **CSS**
- **Figma** for the UI design
